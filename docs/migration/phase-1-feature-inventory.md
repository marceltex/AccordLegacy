## Integration notes

- Accord seams for later phases: `ui/LibraryViewModel.kt`, `logic/utils/MediaStoreUtils.kt`, `ui/fragments/SearchFragment.kt`, `ui/adapters/*`, `logic/GramophonePlaybackService.kt`, and lyric views/widget. Adapt functionality to them rather than copying Gramophone presentation.
- Gramophone's `Reader` is the current scan reference; the MediaStoreCompat library and coroutine/Media3 versions must be reconciled with Accord's Phase 2 baseline before dependency changes.
- Keep Room intact until every playlist/favorite caller has moved in Phase 4. No migration is needed because the user installs fresh.
- Gramophone manifest additions (search and playback intents, picker activities, providers, optional feature/permission declarations) are not blanket requirements; justify each by an adopted Accord flow.
- Current Gramophone service includes broader features such as pinned/multiple queues and lyrics-aware notifications. Phase 5 should prioritize everyday behavior and document any selected subset; optional audio remains deferred.
